| SPY 추세 | 〃 | 〃 | 〃 |

| 합계 | 신호 | 대응 |
|---|---|---|
| +3 이상 | 🟢 공격 | 돌파 매수 적극, 정상 비중 |
| −2 ~ +2 | 🟡 선별 | 가장 강한 셋업만, 비중 축소, 손절 짧게 |
| −3 이하 | 🔴 방어 | 신규 롱 자제, 현금 확대, 숏 스캐너가 유리 |

- **분산일**: 종가가 0.2% 이상 하락하면서 거래량이 전날보다 많은 날입니다. 그날 종가보다 5% 넘게 오르면 지워집니다 (IBD 방식).
- **200일선 위 비율**: 참고용으로만 보여 주고, 점수에는 넣지 않습니다.
- **팔로우스루 데이**: 52주 고점 대비 7% 이상 조정을 받았다면 "반등 시도 n일째"를 함께 보여 줍니다. 반등 4일째 이후 1.5% 이상 상승하면서 거래량도 늘면 "✅ 팔로우스루 데이 → 시험 매수 구간"으로 표시합니다.
- **신호 변경**: 어제와 신호가 달라지면 제목 옆에 "← 어제 🟢에서 하락"처럼 표시합니다.

## ② ETF 신호등

| 지표 | +1 | 0 | −1 |
|---|---|---|---|
| 단기 추세 | 21EMA·50SMA 위 | 21EMA 아래, 50SMA 위 | 50SMA 아래 |
| 장기 추세 | 50SMA > 200SMA이면서 200SMA 상승 | 둘 중 하나만 | 둘 다 아님 |
| 분산일 (ETF 자체, 25일) | 3일 이하 | 4~5일 | 6일 이상 |
| RS (3개월 수익률 순위) | 상위 30% | 중간 | 하위 30% |
| 52주 고점과의 거리 | 10% 이내 | 10~25% | 25% 넘게 아래 |

판정은 +3 이상이면 🟢 강세, −3 이하이면 🔴 약세, 그 사이는 🟡 중립입니다. 점수 계산에서 예외가 두 가지 있고, 해당 ETF에는 표에 `*`가 붙습니다.

- **레버리지·인버스** (TQQQ, SQQQ, SOXL, SOXS, KORU): 52주 고점 거리 점수를 뺍니다. 하락폭이 과장되기 때문입니다.
- **채권·금·원자재** (TLT, IEF, LQD, HYG, GLD, DBC): 분산일 점수를 뺍니다. 주식처럼 기관 매도를 보여 주는 지표가 아니기 때문입니다.

## 디스코드 알림 모양

```
🚦 시장환경 | 2026-10-15 마감
🟡 선별 (-1점)   ← 어제 🟢에서 하락

QQQ       21EMA 위 / 50SMA 위             +1
SPY       21EMA 아래 / 50SMA 아래         -1
분산일    QQQ 3일 · SPY 6일               -1
50일선↑   58%  (690종목 중)                0
200일선↑  67%                           참고
신고/신저 27 / 12  (5일 132 / 64)         +1
VIX       23.1  (+1.9)                     0
→ 가장 강한 셋업만, 비중 축소, 손절 짧게

🔄 신호 바뀐 ETF (2)
XLE    에너지          🟡→🟢  +3점
SMH    반도체          🟢→🔴  -3점

🟢 강세 (24)
TICKER 설명            점수   RS    3M%  고점%  분산
XLU    유틸리티          +5    1  +32.8   -0.6     2
...
🟡 중립 (…)  /  🔴 약세 (…)
```

| 열 | 의미 |
|---|---|
| 점수 | 5개 지표 합계 (−5 ~ +5) |
| RS | 3개월 수익률 순위 (1 = 가장 강함) |
| 3M% | 3개월 수익률 |
| 고점% | 52주 고점 대비 현재가 |
| 분산 | 최근 25거래일 분산일 수 |

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `시장-신호등`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널이 새 채널인지 확인 → URL 복사. ETF 거래량 채널과는 **다른 웹후크**를 써야 합니다.
2. **GitHub**: New repository (Public) → `light.py`, `etfs.txt`, `watchlist.txt`, `requirements.txt`, `README.md` 업로드 → **Add file → Create new file**로 `.github/workflows/main.yml` 만들고 zip 안의 내용 붙여넣기
3. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 1번 웹후크 주소
4. **Actions → Market Light → Run workflow**로 테스트 (2~4분 걸림)

첫 실행에는 비교할 어제 신호가 없어서 "🔄 신호 바뀐 ETF"가 나오지 않습니다. 다음 거래일부터 나옵니다.
